# 마리오네트 펜싱 · PUPPET FENCING

대전 · 2인 · 웹캠(손 인식), 키보드 보조

웹캠 앞에 두 사람이 손을 하나씩 올리고, 손가락으로 졸라맨 검객을 줄 인형처럼 조종해 펜싱으로 겨룹니다. 다섯 손가락에 찌르기, 패리, 런지, 웅크리기가 하나씩 걸려 있어서, 손가락을 얼마나 빨리 정확하게 움직이느냐로 승부가 갈립니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열고 **카메라 켜고 시작**을 누른 뒤 카메라 권한을 허용합니다. 로컬 서버로 열어도 됩니다.

```
cd puppet_fencing
python -m http.server 8000   # http://localhost:8000
```

- 처음 실행할 때 손 인식 모델(약 8MB)을 인터넷에서 내려받습니다.
- 카메라 없이 하려면 **키보드로 시작**을 누릅니다.

## 조작

### 손

웹캠 화면의 왼쪽 절반에 있는 손이 P1(RED), 오른쪽 절반에 있는 손이 P2(GREEN)입니다. 화면은 거울처럼 보입니다. 기본 자세는 **엄지를 세운 손가락 총 모양**입니다. 검지로 상대를 겨누고 나머지 손가락은 접습니다.

| 입력 | 동작 |
| --- | --- |
| 손바닥 좌우 | 앞뒤 이동 |
| 검지 방향 | 칼끝 조준 |
| 검지 빠르게 펴기 | 찌르기 (팔 뻗기) |
| 엄지 접기 | 패리: 0.35초 동안 막는 자세, 재사용 0.9초 |
| 중지·약지 펴기 | 런지: 사거리가 늘지만 이동이 느려짐 |
| 새끼 펴기 | 웅크리기: 높은 찌르기를 피하지만 이동이 느려짐 |
| 두 선수 모두 손바닥 활짝 펴고 1.5초 | 재대결 (경기 종료 화면) |

화면 아래 손가락별 게이지로 지금 어떤 동작이 들어가는지 볼 수 있습니다. 무대 위 조종대에는 내 손 모양이 그려지고, 손가락 끝에서 그 손가락이 움직이는 몸 부위로 줄이 이어집니다(엄지→칼 든 팔꿈치, 검지→칼 든 손, 중지→앞무릎, 약지→뒷무릎, 새끼→머리).

### 키보드

손이 인식되지 않는 선수는 자동으로 키보드 조작으로 바뀝니다. 혼자 테스트할 때도 쓸 수 있습니다.

| 동작 | P1 | P2 |
| --- | --- | --- |
| 이동 | `A` / `D` | `←` / `→` |
| 조준 | `W` / `S` | `↑` / `↓` |
| 찌르기 | `F` | `.` 또는 `K` |
| 런지 | `G` | `/` 또는 `L` |
| 패리 | `E` | `,` 또는 `J` |
| 웅크리기 | `Q` | 오른쪽 `Shift` 또는 `I` |
| 재대결 | `Space` | `Space` |

## 규칙

- **5점**을 먼저 얻으면 승리합니다.
- 에페 규칙이라 전신이 유효면입니다. 칼끝이 **몸 기준으로** 빠르게 앞으로 나가면서 상대 몸에 닿아야 득점합니다. 걷기만 해서는 찌를 수 없고, 검지로 팔을 뻗거나 런지해야 합니다.
- 두 선수가 거의 동시에 찌르면 양쪽 모두 1점입니다. 둘 다 매치 포인트일 때의 동시 찌르기는 무효입니다.
- 칼끼리 부딪히면 더 빠르게 휘두른 쪽이 상대 칼을 밀어냅니다. 상대를 득점 불가 상태로 만드는 건 엄지 패리뿐입니다.
  - 패리 자세에서 칼이 닿으면 상대 칼을 튕겨내고, 상대는 **0.9초** 동안 득점할 수 없습니다.
  - 상대 찌르기가 닿기 약 0.1~0.3초 전에 접으면 막을 수 있고, 칼이 맞닿아 있을 때 접으면 상대 칼을 쳐내 공격 기회를 만들 수 있습니다.
- 득점 후에는 두 선수 모두 출발선 뒤로 물러나야 En garde → Prêts? → Allez! 신호와 함께 다음 라운드가 시작됩니다.

## 팁

- 손 전체가 카메라에 보이도록 40~70cm 정도 떨어지고, 밝은 곳에서 하세요.
- 손을 옆으로 눕혀 검지가 상대 쪽을 가리키게 하면 칼끝 조준이 가장 정확합니다.
- 런지는 사거리가 길지만 발이 무거워집니다. 빗나가면 반격당하기 쉽습니다.

## 사용한 기술

- 손 인식: [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) `@mediapipe/tasks-vision@0.10.14` (jsdelivr CDN, 브라우저 안에서 실행)
- 캐릭터, 무대, 효과음: Canvas 2D와 Web Audio로 코드에서 직접 그리고 합성
- `tracker.js`: 손 관절 21개를 받아 손가락별 조작값(조준 각도, 펴짐 정도, 엄지 접힘)을 계산
