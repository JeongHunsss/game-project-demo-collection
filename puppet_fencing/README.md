# 마리오네트 펜싱 · PUPPET FENCING

웹캠으로 손가락 관절을 인식해 졸라맨 검객을 마리오네트처럼 조종하는 2인용 펜싱 게임입니다. 손 인식은 MediaPipe Hand Landmarker(브라우저에서 실행)를 사용하며, 캐릭터·무대·효과음은 모두 코드로 그립니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 바로 열거나, 로컬 서버로 엽니다.

```
cd puppet_fencing
python -m http.server 8000
```

서버로 열 때는 http://localhost:8000 에 접속합니다. 그다음 **카메라 켜고 시작**을 누르고 카메라 권한을 허용하세요. 처음 실행할 때 손 인식 모델(약 8MB)을 인터넷에서 내려받습니다.

## 조작 (손)

웹캠 화면의 왼쪽 절반에 있는 손이 P1(RED), 오른쪽 절반에 있는 손이 P2(GREEN)입니다. 화면은 거울처럼 보입니다.

| 손 | 캐릭터 | 쓰임 |
| --- | --- | --- |
| 손바닥 좌우 | 앞뒤 이동 | 거리 조절 |
| 검지 방향 | 칼 방향 | 조준 |
| 검지 펴기 | 팔 뻗기 | 빠르게 펴면 찌르기 |
| 엄지 접기 | 패리 | 0.35초 동안 막는 자세. 칼이 닿으면 상대 칼을 튕겨내고, 상대는 0.9초 동안 득점 불가 (재사용 0.9초) |
| 중지·약지 펴기 | 런지 | 사거리가 늘지만 이동이 느려짐 |
| 새끼 펴기 | 웅크리기 | 높은 찌르기를 피하지만 이동이 느려짐 |

기본 자세는 엄지를 세운 손가락 총 모양(검지로 상대를 겨누고 나머지 손가락은 접기)입니다. 걷기만 해서는 찌를 수 없고, 검지를 뻗거나 런지해서 칼끝이 몸보다 앞으로 빠르게 나가야 득점합니다. 화면 아래 손가락별 게이지로 지금 어떤 동작이 들어가는지 볼 수 있습니다.

무대 위 조종대에는 내 손 모양이 그려지고, 손가락 끝에서 그 손가락이 움직이는 몸 부위로 줄이 이어집니다(엄지→칼 든 팔꿈치, 검지→칼 든 손, 중지→앞무릎, 약지→뒷무릎, 새끼→머리).

## 조작 (키보드)

손이 인식되지 않는 선수는 자동으로 키보드 조작으로 바뀝니다. 혼자 테스트할 때도 쓸 수 있습니다.

- P1: A/D 이동, W/S 조준, F 찌르기, G 런지, E 패리, Q 웅크리기
- P2: ←/→ 이동, ↑/↓ 조준, `.`(또는 K) 찌르기, `/`(또는 L) 런지, `,`(또는 J) 패리, 오른쪽 Shift(또는 I) 웅크리기

## 규칙

- 에페 규칙: 전신이 유효면입니다. 칼끝이 칼날 방향으로 빠르게 나가면서 상대 몸에 닿아야 득점합니다.
- 두 선수가 거의 동시에 찌르면 양쪽 모두 1점을 얻습니다. 둘 다 매치 포인트일 때의 동시 찌르기는 무효입니다.
- 칼끼리 부딪히면 더 빠르게 휘두른 쪽이 상대 칼을 밀어냅니다. 상대를 득점 불가 상태로 만드는 건 엄지 패리뿐입니다. 상대 찌르기가 닿기 약 0.1~0.3초 전에 엄지를 접으면 막을 수 있고, 칼이 맞닿아 있을 때 접으면 상대 칼을 쳐내 공격 기회를 만들 수 있습니다.
- 득점 후에는 두 선수 모두 출발선 뒤로 물러나야 다음 라운드가 시작됩니다.
- 5점을 먼저 얻으면 승리합니다. 재대결은 Space 또는 두 선수가 손바닥을 활짝 펴고 1.5초 유지하면 됩니다.

## 팁

- 손 전체가 카메라에 보이도록 40~70cm 정도 떨어지고, 밝은 곳에서 하세요.
- 손을 옆으로 눕혀 검지가 상대 쪽을 가리키게 하면 칼끝 조준이 가장 정확합니다.
