# 훨훨 · FLUTTER FLIGHT

액션 · 1인 · 웹캠(몸 인식), 키보드 보조

내 몸이 새가 되는 1인칭 3D 비행 게임입니다. 웹캠 앞에서 팔을 퍼덕이면 날아오르고, 가만히 있으면 떨어집니다. 몸을 기울여 방향을 틀며 나무, 열기구, 바위벽, 번개, 바람개비 사이를 빠져나가세요. 얼마나 멀리 날 수 있는지 겨루는 끝없는 비행입니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열고 **카메라로 날기**를 누른 뒤 카메라 권한을 허용합니다.

- 처음 실행할 때 몸 인식 모델과 3D 라이브러리를 인터넷에서 내려받습니다.
- 카메라에서 2m쯤 떨어져, 허리 위 상체와 양팔을 쭉 펴도 화면 안에 다 들어오게 서세요. 상체가 인식되면 3·2·1 카운트다운 뒤 출발합니다.
- 플레이 중 몸이 화면에서 1초 넘게 벗어나면 자동으로 멈추고, 다시 보이면 이어서 날아갑니다.
- 웹캠이 없으면 **키보드로 날기**를 누릅니다.

## 조작

### 몸 (웹캠)

| 동작 | 결과 |
| --- | --- |
| 🙌 팔을 어깨 높이 위로 들었다가 ⬇️ 아래로 내려치기 | 날갯짓: 위로 솟구침 (높이 들었다 내려칠수록 세게) |
| 가만히 있기 | 중력에 따라 떨어짐 |
| ↙️ 몸(어깨)을 왼쪽으로 기울이기 | 왼쪽으로 날아감 (3°부터 반응, 17°에서 최대) |
| ↘️ 몸(어깨)을 오른쪽으로 기울이기 | 오른쪽으로 날아감 |
| 🙆 두 팔을 양옆으로 쭉 펴고 버티기 | 활공: 초당 최대 2.5m씩 천천히 내려감 |

화면 오른쪽 아래 카메라 미리보기 옆의 막대가 팔 높이를 보여줍니다. 파란 선 위로 올렸다가 주황 선 아래로 내려치면 날갯짓 1회입니다.

### 키보드

| 키 | 동작 |
| --- | --- |
| `Space` / `W` / `↑` | 날갯짓 (누를 때마다 1회) |
| `A` `D` / `←` `→` | 왼쪽 / 오른쪽 |
| `Shift` (누르고 있기) | 활공 |

## 규칙

- 앞으로는 저절로 날아가며 속도가 점점 빨라집니다(14 → 27m/s).
- 하트는 3개입니다.
  - 장애물이나 땅에 부딪히면 하트 1개를 잃습니다. 1.6초 동안 무적이 되고 속도가 조금 줄어듭니다.
  - 땅에 닿으면 튕겨 올라갑니다.
  - 하트를 모두 잃으면 끝납니다.
- 600m마다 지역이 바뀌고, 네 지역을 다 돌면 처음 지역으로 돌아와 더 어려워집니다(바위벽 구멍이 작아지고 장애물이 늘어남).

  | 지역 | 장애물 |
  | --- | --- |
  | 초원 | 🌲 나무, 🎈 위아래로 떠다니는 열기구 |
  | 협곡 | 🪨 바위 기둥(사이로 통과), 구멍 뚫린 바위벽(노란 테두리 구멍으로 통과) |
  | 폭풍 구름 | ⚡ 번개: 노란 기둥이 1.3초 번쩍인 뒤 내리침, 🦅 가로질러 나는 독수리 |
  | 바람개비 언덕 | 돌아가는 바람개비 날개, ⭕ 통과하면 보너스인 고리 |
- 🌻 씨앗과 ⭕ 고리를 모으면 점수가 오릅니다. 가끔 나오는 ❤️는 하트를 1개 채워줍니다.
- **점수** = 비행 거리(m) + 씨앗 × 10 + 고리 × 50. 최고 점수는 브라우저에 저장됩니다.

## 팁

- 날갯짓은 한 번에 2m쯤 오릅니다. 바위벽 구멍처럼 높이를 맞춰야 할 때는 작게 여러 번 퍼덕이세요.
- 높이 떠 있다가 내려가야 할 땐 날갯짓을 멈추고, 너무 빨리 떨어지면 팔을 쭉 펴서 활공하세요.
- 번개 예고 기둥은 내가 있는 쪽을 노립니다. 보이자마자 옆으로 기울이세요.

## 사용한 기술

- 몸 인식: [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) lite 모델, `@mediapipe/tasks-vision@0.10.14` (jsdelivr CDN, 브라우저 안에서 실행)
- `pose.js`: 어깨·손목 위치로 날갯짓, 기울기, 활공을 판정합니다.
  - 팔 높이는 손목이 어깨보다 얼마나 아래에 있는지를 어깨 너비로 나눈 값이라, 카메라와의 거리에 상관없이 같은 동작으로 인식됩니다.
  - 기울기는 두 어깨를 이은 선의 각도로 잽니다.
- 3D: [three.js](https://threejs.org/) `0.149.0` (일반 스크립트 빌드), 툰 셰이딩. 1인칭 날개는 카메라에 붙인 모델입니다.
- 효과음은 Web Audio로 합성했습니다.
