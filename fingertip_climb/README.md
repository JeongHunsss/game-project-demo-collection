# 손끝 클라이밍 · FINGERTIP CLIMB

액션 · 1인 · 웹캠(손 인식), 마우스 보조

웹캠 앞에 두 손을 들면 그 손이 그대로 클라이머의 손이 되는 클라이밍 게임입니다. 주먹을 쥐어 홀드를 잡고, 잡은 손을 아래로 끌어내려 몸을 올립니다. 60m 절벽에는 OK 손 모양으로만 잡히는 홀드, 무너지는 홀드, 낙석, 돌풍, 다이노 점프 같은 기믹이 구간마다 기다립니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열고 **카메라로 시작**을 누른 뒤 카메라 권한을 허용합니다.

- 처음 실행할 때 손 인식 모델(약 8MB)을 인터넷에서 내려받습니다.
- 카메라에서 1m쯤 떨어져, 두 손을 머리 위로 올려도 화면 안에 다 보이게 서세요. 밝은 곳이 잘 인식됩니다.
- 손바닥을 **화면 위쪽 30% 높이**까지만 올려도 클라이머의 팔이 끝까지 뻗습니다. 손이 화면 밖으로 나가면 인식이 끊기니 그보다 높이 올릴 필요는 없습니다. 화면 아래쪽 90% 높이까지 내리면 끝까지 끌어당깁니다.
- 웹캠이 없으면 **마우스로 시작**을 누릅니다.

## 조작

### 손 (웹캠)

웹캠 화면의 왼쪽에 있는 손이 클라이머의 왼손, 오른쪽에 있는 손이 오른손입니다. 화면은 거울처럼 보입니다.

| 손 | 동작 |
| --- | --- |
| 손 움직이기 | 클라이머 손 이동 (팔 길이 안에서) |
| ✊ 주먹 | 손이 닿은 홀드 잡기 |
| ✊ 잡은 채 손을 아래로 | 몸을 끌어올리기 |
| ✊ 잡은 채 손을 옆으로 | 몸을 옆으로 옮기기 |
| 🖐 손 펴기 | 놓기 |
| 👌 OK (엄지·검지 끝을 붙이고 나머지는 펴기) | 노란 작은 홀드(크림프) 잡기 |
| 두 손으로 잡고 있다가 🖐🖐 두 손을 동시에 펴며 위로 뻗기 | 다이노 점프 |

낙석, 가시, 돌풍, 지침, 무너짐 때문에 사고로 놓친 손은 한 번 폈다가 다시 쥐어야 잡힙니다.

### 마우스

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 두 손을 함께 이동 |
| 왼쪽 버튼 누르고 있기 / 오른쪽 버튼 누르고 있기 | 왼손 / 오른손 쥐기 |
| `Shift` + 버튼 | OK 모양으로 쥐기 |
| 두 손으로 잡은 상태에서 `Space` | 다이노 점프 |

## 규칙

- 높이 **60m 정상의 깃발**에 올라서면 완주입니다. 10m마다 체크포인트 렛지가 있습니다.
- 렛지 가장자리까지 몸을 끌어올리면 자동으로 올라섭니다.
- 체크포인트보다 5m 넘게 떨어지면 체크포인트로 돌아가고 추락 횟수가 1 늘어납니다.
- **팔 힘**은 매달려 있는 동안 줄어듭니다. 0이 되면 손이 미끄러집니다.

  | 상황 | 초당 변화 |
  | --- | --- |
  | 한 손으로 매달림 | −8 |
  | 두 손으로 매달림 | −3.5 |
  | 젖은 홀드 (손마다 추가) | −10 (한 손일 때) / −4 (두 손일 때) |
  | 크림프 (손마다 추가) | −2 |
  | 땅이나 렛지에 서 있음 | +40 |

  다 빠지면 서서 30 이상 회복할 때까지 아무것도 잡을 수 없습니다.

- **구간과 기믹**

  | 높이 | 구간 | 기믹 |
  | --- | --- | --- |
  | 0~10m | 출발 바위 | 기본 홀드로 연습 |
  | 10~20m | 작은 홀드 구간 | 🟡 크림프: 👌 OK 모양으로만 잡힘 |
  | 20~30m | 무너지는 절벽 | 금 간 홀드: 잡고 1.4초 뒤 무너짐(5초 뒤 복구). 낙석: ▼ 표시와 붉은 기둥이 뜨고 1.4초 뒤 떨어짐. 맞으면 두 손을 놓침. |
  | 30~40m | 폭포 벽 | 💧 젖은 홀드: 팔 힘이 빨리 빠짐. 🟣 움직이는 홀드: 좌우로 오감. |
  | 40~50m | 바람 능선 | 💨 돌풍: 화살표 예고 1.3초 뒤 2.2초 동안 붐. 한 손으로 0.8초 넘게 버티면 날아감. 두 손이면 안전. 🔴 가시 홀드: 잡으면 팔 힘 −25, 손을 놓침. |
  | 50~60m | 다이노 갭 | 🚀 팔이 닿지 않는 3m 간격. 아래 큰 홀드 두 개를 두 손으로 잡고 다이노 점프로 넘어야 함. |
- 💎 보석은 손이나 몸으로 스치면 모입니다.
- **점수**: 10000 − 시간(초)×20 − 추락×300 + 보석×200
  - 8000 이상 S, 6500 이상 A, 5000 이상 B, 그 아래 C
  - 최고 기록은 브라우저에 저장됩니다.

## 팁

- 잡은 손을 내리기 전에 옆으로 움직여 몸을 다음 홀드 쪽으로 옮겨 두면 손이 닿기 쉽습니다.
- 돌풍 화살표가 보이면 다른 손도 같은 홀드나 옆 홀드에 걸어 두세요.
- 다이노는 두 손을 거의 동시에 펴야 합니다. 먼저 두 손으로 몸을 끝까지 끌어내린 뒤 손을 위로 확 뻗으면서 펴면 더 높이 뜁니다.

## 사용한 기술

- 손 인식: [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) `@mediapipe/tasks-vision@0.10.14` (jsdelivr CDN, 브라우저 안에서 실행)
- `tracker.js`: 손 관절 21개로 손 모양을 판별합니다.
  - 네 손가락이 모두 접히면 ✊
  - 엄지·검지 끝이 붙고 나머지가 펴져 있으면 👌
  - 그 밖에는 🖐
  - 같은 모양이 두 프레임 연속 나와야 바뀌고, 인식이 잠깐 끊겨도 0.4초 동안은 마지막 모양을 유지합니다.
- 게임 화면, 캐릭터, 효과음은 Canvas 2D와 Web Audio로 코드에서 직접 그리고 합성했습니다.
- 코스는 고정 시드로 생성합니다. 구간마다 반드시 오를 수 있는 길을 먼저 깔고 그 주변에 함정과 여분 홀드를 둡니다.
