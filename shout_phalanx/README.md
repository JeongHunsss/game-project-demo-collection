# 외쳐라, 방진대! · SHOUT PHALANX

전략 액션 · 1인 · 마이크(음성 인식), 키보드/마우스 보조

창과 방패를 든 귀여운 병사 12명을 목소리로 지휘해 협곡의 적을 물리치는 3D 스테이지형 게임입니다. 화살비, 기병 돌격, 투석기, 거인이 공격하기 전에 바닥에 예고 표시가 뜹니다. 그걸 보고 "방패!", "산개!", "스파르타!"처럼 알맞은 명령을 외쳐야 방진이 살아남습니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열고 **출정하기**를 누른 뒤 마이크 권한을 허용합니다.

- 음성 인식은 브라우저의 Web Speech API(한국어)를 쓰므로 **인터넷 연결**이 필요합니다. Firefox 등 지원하지 않는 브라우저에서는 키보드와 화면 버튼으로 플레이합니다.
- 3D 그래픽 라이브러리(three.js)를 CDN에서 불러오므로 처음 실행할 때도 인터넷이 필요합니다.
- 화면 아래 **마이크 버튼**으로 음성 인식을 켜고 끌 수 있습니다.

## 조작

### 음성 명령

명령어는 문장 속에 섞여 있어도 알아듣습니다. "다들 앞으로 가서 공격해!"라고 말하면 전진과 공격이 차례로 실행됩니다.

| 외칠 말 (같은 뜻의 말) | 동작 |
| --- | --- |
| 전진 (앞으로, 진격) | 앞으로 행군 |
| 후퇴 (뒤로, 물러나) | 뒤로 물러남 |
| 정지 (멈춰, 그만) | 제자리에 멈춤 |
| 왼쪽 / 오른쪽 (좌로 / 우로) | 대형 전체를 옆으로 4칸 이동 |
| 공격 (쳐라, 싸워) | 전진하며 가까운 적에게 붙어 빠르게 찌름 |
| 방패 (방어, 막아) | **방패벽**: 화살과 기병 돌격을 막음. 느려지고 공격이 약해짐 |
| 산개 (흩어져, 퍼져) | 간격을 넓혀 바위와 내려찍기 피해를 덜 받음. 근접전에 약해짐 |
| 모여 (집합, 대형) | 기본 밀집 대형으로 복귀 |
| 투창 (던져, 발사) | 모든 병사가 앞쪽 적에게 창을 던짐. 재사용 8초 |
| 돌격 (돌진) | 2초 동안 달려가 부딪힌 적을 날려 보냄. 끝나면 3초 동안 지침. 재사용 12초 |
| 스파르타 (함성) | 7초 동안 공격력 1.5배, 받는 피해 40% 감소, 가까운 적을 밀쳐냄. 재사용 20초 |

### 키보드 / 마우스

화면 아래 명령 버튼을 눌러도 됩니다.

| 키 | 명령 |
| --- | --- |
| `W` / `S` / `X`(또는 `Space`) | 전진 / 후퇴 / 정지 |
| `A` / `D` | 왼쪽 / 오른쪽 |
| `E` | 공격 |
| `Q` / `Z` / `C` | 방패 / 산개 / 모여 |
| `F` / `R` / `G` | 투창 / 돌격 / 스파르타 |
| `Esc` | 일시정지 |

## 규칙

- 스테이지는 5개이고, 앞 스테이지를 깨면 다음 스테이지가 열립니다.
  1. **첫 행군**: 보병만 나오는 연습 스테이지
  2. **화살비**: 궁수
  3. **기병 돌격**: 기병
  4. **투석기 요새**: 투석기
  5. **거인의 협곡**: 보스 거인 대장 볼그
- 전진하면 정해진 지점마다 적 웨이브가 나타납니다. 모든 웨이브를 물리치면 승리, 병사 12명이 모두 쓰러지면 패배입니다.
- 살아 있는 적을 지나쳐 갈 수 없습니다. 길을 막는 적은 쓰러뜨려야 합니다.
- 별점은 남은 병력(병사 체력 합계)으로 매깁니다. 70% 이상이면 ★★★, 40% 이상이면 ★★, 그 아래는 ★입니다.
- 적이 강한 공격을 하기 전에는 예고가 나옵니다.

  | 예고 | 공격 | 대응 |
  | --- | --- | --- |
  | 붉은 원 | 궁수 일제 사격 (2.3초 뒤) | 방패 |
  | 바닥에 깔리는 붉은 길 | 기병·거인 돌진 | 방패. 막으면 돌진한 적이 크게 다치고 기절함 |
  | 주황 원 | 투석기 바위 (2.8초 뒤) | 방패로는 못 막음. 산개, 또는 왼쪽/오른쪽으로 피하기 |
  | 보라 원 | 거인의 내려찍기 (2.1초 뒤) | 후퇴, 또는 왼쪽/오른쪽으로 피하기 |
- 방패벽과 산개는 상황이 끝나면 "모여!"로 풀어야 다시 세게 찌릅니다.

## 팁

- 음성 인식은 0.5~1초 정도 늦게 반응합니다. 예고 표시가 보이자마자 외치세요.
- 멀리서 기다리는 기병이나 궁수는 "투창!"으로 미리 줄여 두면 편합니다.
- 거인이 돌진할 때 방패벽으로 막으면 거인이 기절합니다. 그때 "스파르타!"로 몰아치세요.

## 사용한 기술

- 3D: [three.js](https://threejs.org/) `0.149.0` (jsdelivr CDN, 일반 스크립트 빌드), 툰 셰이딩과 그림자
- 음성 인식: Web Speech API (`ko-KR`, 연속 인식과 중간 결과 사용). `voice.js`가 문장에서 명령어를 찾아 순서대로 실행하고, 같은 말이 두 번 실행되지 않게 막습니다.
- 캐릭터, 지형, 효과음은 모두 코드로 만들었습니다(외부 모델이나 음원 없음).
