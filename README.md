# 🎮 game-project-demo-collection

심심할 때마다 떠오른 아이디어로 만드는 작은 게임 모음입니다. 플랫폼은 게임마다 다를 수 있고, 웹 게임은 설치 없이 브라우저에서 바로 실행됩니다.

## 플레이 방법

1. 이 저장소를 clone 하거나 ZIP으로 내려받습니다.
2. 아래 목록에서 게임 이름을 누르면 그 게임의 README가 열립니다.
3. README의 **실행** 항목을 따라 실행합니다. 웹 게임은 폴더의 `index.html`을 Chrome이나 Edge로 열면 됩니다.

웹이 아닌 게임은 목록의 한 줄 소개 끝에 `(Windows · Unity)`처럼 플랫폼을 적어 둡니다.

## 저장소 구조

- 게임 하나가 폴더 하나입니다. 폴더 안의 `README.md`에 게임 소개, 실행 방법, 조작이 있습니다.
- 게임은 게임마다 `game/<이름>` 브랜치와 PR로 추가합니다. 작업 규칙은 [CLAUDE.md](CLAUDE.md)를 참고하세요.
