# 🎮 game-project-demo-collection

심심할 때마다 떠오른 아이디어로 만드는 작은 브라우저 게임 모음입니다. 모든 게임은 설치나 빌드 없이 브라우저에서 바로 실행됩니다.

## 플레이 방법

1. 이 저장소를 clone 하거나 ZIP으로 내려받습니다.
2. 아래 목록에서 게임을 골라 그 폴더의 `index.html`을 Chrome 또는 Edge로 엽니다.
3. 자세한 조작과 규칙은 게임 이름을 누르면 나오는 게임별 README에 있습니다.

## 저장소 구조

- 게임 하나가 폴더 하나입니다. 폴더 안의 `index.html`이 시작점이고, `README.md`에 게임 설명이 있습니다.
- 게임은 게임마다 `game/<이름>` 브랜치와 PR로 추가합니다. 작업 규칙은 [CLAUDE.md](CLAUDE.md)를 참고하세요.
